# car# 🚗 Hand Gesture Controlled Car Racing Game
https://vercel.com/deekshithanougari19-bot/car/settings/domains
A fun and interactive **Car Racing Game controlled using hand gestures** through the computer camera. The player can control the car using finger and hand movements instead of traditional keyboard controls.

## 🎮 Project Overview

The Hand Gesture Controlled Car Racing Game combines **web development, computer vision, and gesture-based interaction** to create an interactive gaming experience.

The camera detects the player's hand movements and converts specific gestures into game controls such as:

* ⬆️ Increase car speed
* ⬇️ Decrease car speed
* 🛑 Stop the car
* ▶️ Start the game
* ↔️ Move the car
* 💥 Detect collisions
* 🔄 Restart the game after an accident

## 🕹️ Controls

| Hand Gesture           | Action         |
| ---------------------- | -------------- |
| ☝️ One finger          | Increase speed |
| ✌️ Two fingers         | Decrease speed |
| ✋ Open hand            | Stop           |
| 👍 Start gesture       | Start game     |
| 👈 Hand movement left  | Move car left  |
| 👉 Hand movement right | Move car right |

> Gesture controls can be customized in the JavaScript code depending on the implementation.

## 📸 How the Game Works

1. Open the game website.
2. Allow camera permission.
3. Position your hand in front of the camera.
4. The system detects your hand.
5. Your gesture is converted into a game command.
6. The car moves according to your gesture.
7. Avoid other vehicles and obstacles.
8. If the car crashes, the game stops/restarts according to the game logic.
9. Continue playing and try to achieve a high score.
